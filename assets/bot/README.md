# Оформлення ботів

| Файл | Що |
|---|---|
| `prod.svg` / `preview.svg` | джерела (лише контури, без шрифтів) |
| `prod.png` / `preview.png` | 640×640, для перегляду й `@BotFather` `/setuserpic` |
| `prod.jpg` / `preview.jpg` | 640×640 JPEG: Bot API `setMyProfilePhoto` приймає лише `.JPG` |

- **Робочий** — тепла жовто-червона аватарка, біла гантеля, зелена галочка «виконано». Назва «💪 Тренер».
- **Тестовий** — холодна фіолетово-синя, та сама гантеля, жовто-чорна стрічка «TEST». Назва «🧪 Тренер · тест».

Усе важливе лежить усередині вписаного кола: Telegram обрізає аватарку колом.

Перегенерація після правки SVG (потрібні `pip install resvg-py pillow`, лише для цього кроку):

```powershell
python assets/bot/render.py
```

Ставить аватарки й назви `scripts/set-bot-profile.ps1` (див. `docs/RUNBOOK.md`, «Профіль бота»).
