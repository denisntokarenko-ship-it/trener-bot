# Специфікація — індекс

| Файл | Що всередині | Хто читає |
|---|---|---|
| `00-common.md` | стан проєкту, терміни, ролі, нефункціональні вимоги | **усі, завжди** |
| `phase-0.md` | каркас: вебхук і секрет, білий список, дедуп, `/start`, set-webhook, бекап і відкат; схема `users`, `processed_updates` | завдання Фази 0 |
| `phase-1.md` | тренування, зріз 1: схема фази 1, каталог, кроки ваг, правила прогресії з таблицею випадків | 1.1, 1.2; 1.3–1.5 — разом із `phase-1-flow.md` |
| `phase-1-flow.md` | тренування, зріз 2: потік `/trening` (стани, екран, `callback_data`, вага, заміна, пропуск, оцінка, застарілі кнопки), `/progres`, `/prohrama`, крон | 1.3, 1.4, 1.5 |
| `phase-1b.md` | персоналізація: анкета, ціль → параметри плану, профіль і стартові ваги, генератор плану, назви тренувань, відео, гайд оформлення | завдання 1b.1–1b.5 |
| `phase-2.md` | метрики й нагадування: вага тіла, повний `/progres`, нагадування й недільний звіт, `/nalashtuvannia`, переходи часу | завдання 2.1–2.5 |
| `phase-3.md` | їжа, зріз 1: схема, сид продуктів (USDA, CC0), норма КБЖУ, `/yizha`, корекція норми за вагою | 3.1, 3.2, 3.4; 3.3 — розділи 1–2 |
| `phase-3-photo.md` | їжа, зріз 2: потік фото, JSON-схема, ліміт витрат ШІ (резервування), ціни | 3.3 |
| `phase-4.md` | ШІ-тренер: `ai_proposals`/`chat_turns`, 6 інструментів, системний промпт, маршрутизація тексту, цикл і ліміти, пропозиції, коментар у звіті | завдання 4.1–4.4 |
| `decisions.md` | ухвалені рішення з причинами, лише дописується | хто сумнівається «чому так» |
| `open-questions.md` | невідоме, блокуючі вгорі | перед стартом фази |

Правило: читаєш `00-common.md` + зріз своєї фази. Спеку цілком — ніколи.
Бюджет: кожен файл ≤ 40 КБ, тримає `npm run check:docs` (до 0.3 — `bash scripts/check-docs.sh`).
