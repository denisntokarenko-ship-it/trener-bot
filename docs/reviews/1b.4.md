## Дрібниці

1. `texts.ts:373` «…тому це питання не пропустити» — неграматично; краще «його не можна пропустити».
2. `texts.ts:63` «Привіт, ${імʼя}!» — кличний відмінок не будується автоматично («Привіт, Денис!»); безпечніше «Привіт! 👋» без імені або прийняти як відоме обмеження.
3. `texts.ts:148`, `:188` «Як тяжко було?», «Тяжкість» — у літературній мові про навантаження «важко / важкість» (або «складність»); «тяжко» — розмовне. Узгодити з `effort`-термінологією спеки.
4. `texts.ts:70` `NO_PROGRAM` показує користувачу «сид (docs/RUNBOOK.md)» — внутрішній жаргон і шлях до документа в повідомленні бота; краще «Програму не знайдено. Пройди анкету: /start».
5. `texts.ts:387` «Я не братиму для тебе вправи, які це навантажують» — незграбно; «Не включатиму вправи, що навантажують ці місця».
6. У `main` (не в PR): `MUSCLE_UK.core = "кора"` — у фітнес-термінології «кор» (м'язи кору). Виправляти окремо.
7. `callbacks.ts` — повідомлення винятків перекладено англійською лише щоб пройти тест-греп кирилиці; діагностика для розробника, на користувача не впливає, але це зміна поза «текстами бота».
8. Мутант N5 (`clip`: `TELEGRAM_TEXT_MAX - 1` → `+ 5`) вижив: тести `clip` мають лише багаторядковий вхід, де різання йде по `\n` раніше за межу; гілка «один довгий рядок без `\n»` (`texts.ts`, `replace(/<[^>]*$|&[#a-z0-9]*$/i…)`) не покрита. Недосяжно з поточних екранів (нотатки обрізаються `short()`, текст зі слотами багаторядковий) — лише для повноти.
