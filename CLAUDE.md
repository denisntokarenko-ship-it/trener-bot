# Тренер

Telegram-бот-щоденник тренувань для одного користувача (початківець, full body A/B, 3 рази на тиждень): кнопки в залі, прогресія кодом, далі вага тіла, їжа за фото й ШІ-тренер.
Стек: Cloudflare Workers + D1 + Drizzle + grammY + `@anthropic-ai/sdk`, TypeScript, vitest. Мова бота — українська.
Документи: [docs/PLAN.md](docs/PLAN.md) (рішення, стек, архітектура) · [docs/spec/README.md](docs/spec/README.md) (специфікація) · [docs/PROGRESS.md](docs/PROGRESS.md) (ворота й статус) · [docs/PROMPTS.md](docs/PROMPTS.md) (промпти завдань).

## Процес

- **Ворота:** наступне завдання стартує, лише коли попереднє ✅ у `docs/PROGRESS.md` на `origin/main` (і рев'ю ✅, де воно ⬜).
- **Гілка** від свіжого `origin/main`: `git fetch && git switch -c <гілка> origin/main`. Назва гілки — з промпту завдання.
- **Огорожа обсягу:** робиш лише те, що в «Робиш» завдання. Поза ним — зупинись і спитай.
- **Без субагентів** у реалізації.
- **Секрети** не вводиш і не друкуєш (токен бота, ключ Anthropic, `.dev.vars`). Команду готуєш — виконує людина.
- **PR** відкриваєш, не мержиш.

## Контекст

- Читаєш зріз своєї фази `docs/spec/phase-N.md` + `docs/spec/00-common.md`. Спеку цілком — ніколи.
- Бюджет 40 КБ на файл (спека, CLAUDE.md, PROGRESS.md) тримає `npm run check:docs` у CI.
- Довгий вивід (лог, дамп, дерево файлів, `wrangler tail`) — у файл; у контекст лише підсумок. Тести під час ітерації — `npx vitest run --reporter=dot`.

## Архітектурні правила

- Доступ до D1 — лише через `src/db/repo.ts`; кожна функція приймає `userId`.
- `src/bot/**` не імпортує `drizzle-orm` і `src/db/client` напряму (тест-грепом).
- Час у БД — UTC мс (`INTEGER`); локальна дата — з `users.tz`.
- Прогресія й формули — чисті функції без I/O і без `Date.now` (час — параметром).
- ШІ лише класифікує або пропонує; записи робить код після кнопки людини.
- Моделі й ціни Claude — у `src/config.ts`, не в коді.
- Фото в Anthropic — base64; URL файлу Telegram (містить токен бота) нікуди не передається.
- Перед міграцією прода — `npm run backup:prod`.
- Таблиця створюється міграцією у фазі, яка нею користується.
